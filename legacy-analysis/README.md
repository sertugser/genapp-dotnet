# legacy-analysis

Static analysis of the GenApp `base` component. Planned contents:

- `program-inventory.md` – the 31 COBOL programs grouped into the presentation, business and data-access layers, plus 4 support programs (error logging, setup, statistics)
- `call-graph.md` – which program calls which (EXEC CICS LINK)
- `data-dictionary.md` – the shared COMMAREA (copybook `LGCMAREA`) and the 8 Db2 tables
- `use-cases.md` – the 18 business operations with their inputs, outputs and return codes
